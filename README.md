# 一本堂物语：进步

大井巷的「一本堂」，一间做铁壶也卖茶的铺子。

采两片春尾叶合成雨前叶，配净水成一盏生茶；生茶下铁壶慢烧成茶汤，茶汤配好壶萃成特调——两杯特调拼在一起，就是顶级香茗。

长按铁壶进入养护，在壶身划一划就是抹抹茶汁：包浆满了升一阶，浮灰厚了抹得慢，得拿草木灰碱洗一遍。

客人认茶种，也偏好时节。摇扇大爷的茶汤、长衫书生的一壶好茶配一把好壶、老掌柜的一本堂茶壶——**三个订单交齐，这一间铺子就算立住了**。

## 怎么玩

直接用浏览器打开这个页面就能玩，不需要安装任何东西。**手机横过来**体验最好（横屏是左棋盘 / 右信息栏的布局）。

进度自动存在浏览器本地，随时接着做。

- 三种主茶：西湖龙井（绿茶）、九曲红梅（红茶），随时开园换口味
- 壶分四档：生铁壶胚 → 素面铁壶 → 防锈铁壶 → 一本堂茶壶
- 交单会掉「神秘泥模」，敲开出带錾纹的壶（12 种纹样分三套，集齐解锁动态壁纸）
